# 隐患依据速查

国家法规标准优先，江苏／南京补充的安全隐患整改依据速查工具。

在线访问：https://an-0726.github.io/safety-basis/

## 功能

- 按关键词、场所类型、法规类别和地区范围筛选隐患
- 展示隐患描述、法规原文依据、整改措施与适用说明
- 在浏览器中维护隐患库，并支持 JSON 导入、导出
- 纯静态网站，无服务端数据采集，无外部字体或脚本

## 数据说明

网站不自动联网更新法规，也不构成自动法律判定。使用前请核对官方原文、条款、适用范围和现行状态。

浏览器中的修改保存在 `localStorage`，不会自动写回 GitHub。更新所有访客默认看到的资料时，请修改 `data.js`。

## 本地运行

在仓库目录执行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。
