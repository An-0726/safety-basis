# 24例现场用途试点

此命名空间与正式知识实体共享版本管理。`records/` 为18条具体现场缺陷和6条分流/条件不足反例；`evidence/` 为试点官方读取记录或明确待核线索。全部为候选，不能提升上游实体、生命周期或既有审核状态。

`inspectionClass`（检查用途）、`defaultFieldEntry`（默认现场入口）、`recommendedDisposition`（内容处置建议）、`lifecycle`（上游生命周期）分别保存。条件不足的现场检查项仍属于现场类别；具体违规模板为null的边界项只展示判定缺口。公共数据只存匿名来源ID、原件/单元格指纹和定位；企业名称、原文摘录、PDF与前后对比详表留在本地私有交接包。

运行 `python tools/v4/build_unified_release.py --out <独立本地预览目录> --as-of 2026-09-30 --field-profiles-pilot` 后打开 `field-pilot.html`。试点不写入正式search-index，不改变原速查页面。未传开关时不产生试点页面或数据；current和dist输出拒绝试点开关。输出必须重新由构建器生成，不手改包。

构建前校验必填字段、分类、候选状态、可填写模板及审核指纹。指纹绑定完整试点内容、上游隐患、关联集合（新增/删除也算改变）、条款、版本、法规、审核和相关证据；变化后构建失败，须重新进行语义审核，不能自动重签。法律链和本次现场语义审核互不替代。本批正式批准数量为0。

核心查询：可燃气体报警、防爆电气、灭火器。默认显示现场候选；资料、专项、法规义务、待定由用户切换。未设置账号、调查表或强制填长表流程。
