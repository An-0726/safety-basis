# Governed field-profile namespace v1

No real profiles or semantic approvals are automatically created by the backend
implementation. Independently authored drafts remain excluded until reviewed.
Authorized records belong in `records/` and
independent semantic reviews in `reviews/`.

See [the versioned contract](../../../docs/FIELD_PROFILE_CONTRACT.md).
The private `field-profiles-pilot` is a separate candidate-only namespace and is
not imported, migrated or promoted automatically.
