# 检索界面与展示分类约定

## 信息层级

主入口是关键词检索、一个专业分类筛选和地区筛选。场所／设备／作业标签、依据类型和适用方式放入“更多筛选”。高级条件收起后仍显示已选条件和数量，可逐项移除。分享链接中的有效高级条件自动展开；旧链接中不再提供的选项必须明确提示，不静默扩大查询范围。

“清空”只清关键词；“全部重置”恢复关键词和筛选。保留稳定 ID、查询参数、详情跳转、分页、浏览器前进后退和移动端返回结果流程。可见主筛选在移动端至少 44px 高，搜索使用 16px 字号避免输入缩放。

## 两个不同维度

- **专业分类**回答“这条隐患属于哪一类专业问题”。使用 `displayCategory`、受控同名变体和 65 项稳定 ID 展示修正。三个经逐条核对的名称变体归入既有专业分类：特种设备安全 → 特种设备、危险化学品安全 → 危险化学品与危险物质、设备设施安全 → 设备设施；不据此改写源分类或法律范围。
- **现场标签**回答“原始 places 明确记录了什么场所、设备或作业线索”。只从 `places` 投影，不从标题、关键词、描述或适用条件猜标签。它不是法律适用性结论，也不是正式用途分类。

泛化的消防责任、电气安全、培训、职业卫生、应急管理等文字不再生成第二套同名专业分类。未标注具体现场不代表不适用；详情中的源场所和适用条件完整保留。选项只展示当前正式索引中真实存在的标签；结果卡没有具体标签时不重复展示空泛占位语。

反例边界包括：`电动自行车` 不因包含“行车”而成为起重设备；未指明热作业的 `切割作业区` 不自动成为动火；通用场所即使标题写有电梯或气瓶，也不凭标题补场景。

## 可追溯样例

以下均可从 `knowledge/hazards/<稳定ID>.json` 复核：

- `H_ELECTRICAL_ROOM_SMALL_ANIMAL_PROTECTION`：源场所“变配电室”，投影“配电室与配电装置”
- `H_FORKLIFT_UNATTENDED_KEY`：厂内叉车停放区、装卸作业区，投影“叉车与场车”和“仓储与物流”；其 GB/T 36507-2023 第 4.8.1 条仍限定无人看管／轮班结束，源分类“特种设备安全”仅展示为特种设备
- `H_WORKPLACE_CHEM_SDS_MISSING`：源分类“危险化学品安全”，第五十一条对应使用单位向从业人员提供 SDS／标签义务；展示归入危险化学品与危险物质，使用单位及 2026-05-01 起适用的边界不变
- `H_CF_GEN_18`：源分类“设备设施安全”，GB/T 34525-2017 第 7.1.6、9.1 c）对应气瓶放置／立放防倾倒；仅统一为设备设施，不改成特种设备法律认定
- `H065`：气瓶存放区、危险化学品仓库，投影气瓶、危化品储存场所、仓储与物流
- `H078`：经既有稳定 ID 修正的专业分类为安全教育培训，原始场所仍可投影危废贮存场所，两者不混同
- `H001`：源场所只有泛消防责任范围，不从标题“灭火器失压”新增设备标签

在 2026-09-30、基线 a5cc5e5c 的 1,663 条正式索引中，346 条有上述具体现场标签，1,317 条未细分。这个数量只描述展示投影覆盖，不代表正式用途审核完成率。缺失信息应由后续证据审核补全，不能为了覆盖率拼凑标签。

## 搜索解释与效力日期

原词／同义词优先；只有在当前筛选范围没有结果时，才使用既有相关概念或无歧义纠错。界面明确说明这类回退，保留输入框和分享链接中的原查询。未检索到不等于没有法规要求。不增加未经核对的宽泛别名。旧分类链接只有在正式索引的源分类 → 展示分类存在唯一目标时才迁移；多目标或未知值不猜测。安全防护、重大事故隐患判定、危险化学品与危险废物等含义不同或混合类别不随同合并。

`asOf` 是核验快照日期，不声称实时现行性。按中国日期在快照之后提示“未校验此后的法规变化”，恢复可见页面时重新核对日期；不在前台自行改法规状态。旧包只有 `generatedAt` 时明确标为构建日期，不能替代核验日期。

## 验证

- `node --test tests/*.test.mjs`：搜索正反例、回退解释、路由、动态筛选、清空／重置、异步详情和分页
- `python -m unittest discover -s tools/pipeline/tests -v`：源场所样例、不推断反例、无源数据变更、展示投影、Gate 与构建契约
- `tools/browser/audit_search_ux.py --bundle <本地生成包> --out <本地证据目录>`：真实 Chromium 的桌面／移动端、分享恢复、前进后退、键盘与截图，仅访问 localhost；需执行环境允许启动 Chromium

本轮不修改法规范围、条款、正式关联、稳定 ID、Gate 或 field profile 治理契约。生成包和 QA 截图不入版本库。
