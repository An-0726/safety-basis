## 当前连续执行计划

### 1. Excel新增隐患候选处置（已完成）

对Excel中尚未存在于 `knowledge` 的1264个ID逐条处理：

1. 标题和专业描述去重；
2. 识别直接依据标准号、法规名称和条款号；
3. 与公开法规目录、知识条款和私有全文库匹配；
4. 形成“可入库候选”“需补条款”“待核验”“重复/合并”四类结果；
5. 所有记录均进入公开候选层；依据链完整并通过门禁的记录标为“已核验”，其余保留真实待办状态。

### 4. 全文库持续维护（已完成本阶段批次）
