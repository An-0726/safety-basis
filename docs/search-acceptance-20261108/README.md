# 原网站改前改后检索证据

本目录仅含合成问法和公共知识库结果，无企业原话、照片、个人或项目数据。所有标签由助手编制，不冒充独立专业人工标注。

- `dataset-v1.json`：引擎冻结前另取的40条问法，初次实施者未读取。文件字节冻结，后续不更改标注。
- `before-v1.json`：原生产基线`595e30e6b3b2774334f21db1ba8a286ddf58f24e`及其1764条发布包的实际结果。
- `first-pass-v1.json`：新引擎首次独立运行的原始结果；4条失败完整保留。
- `regression-v1.json`：披露失败并修复后的回归结果，此阶段不再视为独立留出。
- `dataset-v2.json`：由未参与搜索实现的审查者只依公开索引、用户需求另取的20条问法；未读第一组或实现调试用例，全部标签位于两版本共同公开集合。
- `before-v2.json`、`first-pass-v2.json`：第二组对旧版和首轮新实现的实际结果。首次新实现仅1/10阳性Top3并有1例否定误配，已触发后续通用解析修复；失败记录保留。
- `regression-v2.json`：第二组披露后修复的回归结果，不再算作独立留出。
- `dataset-v3.json`、`before-v3.json`、`after-v3.json`：最后另取并冻结的20条问法，以及旧版、冻结实现的首次对照结果。新旧直接阳性Top3均为0/10；新实现没有定向误配，但不能以大量零结果宣称验收通过。首测原始结果保留，不再因结果不佳换题。
- `regression-v3.json`：第三组披露后修复的回归结果，不能称为独立留出成绩。
- `scope-review-v1.json`：加强共享否定和状态作用范围后，第一组中两个正向案例退化的中间回归，38/40契约通过。它作为修复过程中发现的回归保留，最终结果另见`regression-v1.json`。
- `browser-first-pass.json`：真实Chromium首轮23项搜索、手机和加载恢复验收的原始20/23结果；两项标题逐字断言与一项测试路由生命周期问题已定位。最终复验以PR 137的Actions和发布后线上检查为准。

报告中的`expected_groups`表示每组可接受的目标集合；逐问题前三必须覆盖各组才算整句对题。定向误匹配只覆盖标注禁止的H或应无直接候选的状态，不能外推成全库误报率。条件建议跳转后的命中单列，不并入原句直接Top3。所有零结果保留，其中“应有内容却为零”另列。

第一组首次运行在本地源码冻结上完成，记录了搜索主文件指纹；最终回归及第二组额外记录全部搜索依赖文件指纹。原始本机路径从公开报告移除，查询、目标、实际结果、版本和指纹未改动。最终源码由本批次提交固定；真实浏览器产物另见对应Actions的`browser-check`。
