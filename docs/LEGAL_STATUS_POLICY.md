# 法规与标准效力口径

## 分层判断

每个依据必须分别记录：

1. 整部文件状态：现行、即将实施、已废止、被替代或待核验。
2. 条款状态：有效、失效、被新条款替代、冲突待复核。
3. 条款强制性：强制、推荐、原强制性条文已废止等。
4. 引用角色：`direct`（直接依据）、`supporting`（支撑依据）、`reference`（参考资料）。

## 不能混为一谈

- “部分强制性条文废止”不等于整本标准废止。
- 推荐性标准仍可作为技术依据，但不能伪装成行政处罚的直接法源。
- 新通用规范与旧标准冲突时，以新通用规范为准；旧标准中未冲突的技术条款仍可引用。
- 已发布但尚未到实施日的版本标记为 `upcoming`，不得无条件替代现行版本。
- 网页打不开、版权受限或没有全文，不等于文件失效；这类项目可保留题录和官方入口，但不得编造条款原文。

GB 50016等建筑防火标准必须按上述分层口径处理，不能仅因部分强制性条文变化而整本剔除。
