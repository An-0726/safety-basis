# 法规与标准效力口径

## 分层判断

每个依据必须分别记录：

1. 整部文件状态：现行、即将实施、已废止、被替代或待核验。
2. 条款状态：有效、失效、被新条款替代、冲突待复核。
3. 条款强制性：强制、推荐、原强制性条文已废止等。
4. 引用角色：`direct`（直接依据）、`fallback`（上位/兜底依据）、`supporting`（支撑依据）。

## 当前正式依据的时间门禁

正式站的“当前依据”按发布包 `asOf` 日期判断。法规版本只有同时满足以下条件，才可以支撑当前隐患：

- `validityStatus=active`；
- `effectiveDate <= asOf`；
- `endDate` 为空，或 `asOf < endDate`；
- 法规身份、版本、条款、证据和关联审核链均通过 Gate。

`upcoming` 表示**已经发布但尚未实施**。它可以保留在 `knowledge/`、本地证据库和“法规全文/资料库”中，用于版本衔接和提前准备，但在实施日前 **不得作为当前正式隐患依据**。实施日到达后应重新核验状态、替代关系和关联，再转为当前依据。

## 不能混为一谈

- “最新发布版本”不等于“当前适用版本”；正式引用优先判断实施日期和检查日期。
- “部分强制性条文废止”不等于整本标准废止。
- 推荐性标准仍可作为技术依据，但不能伪装成行政处罚的直接法源。
- 新通用规范与旧标准冲突时，以新通用规范为准；旧标准中未冲突、仍有效的技术条款可继续引用。
- 已废止/已过 `endDate` 的版本保留历史追溯，但不得支撑当前隐患。
- 网页打不开、版权受限或没有全文，不等于文件失效；这类项目可保留题录和官方入口，但不得编造条款原文。

GB 50016 等建筑防火标准必须按上述分层口径处理，不能仅因部分强制性条文变化而整本剔除。
