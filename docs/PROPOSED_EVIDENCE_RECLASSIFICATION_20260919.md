# 全库 426 条 Proposed 隐患证据缺口全量重新分类与优先推荐报告

> **依据规范**：严格贯彻 PR #62 确立的“本地证据库优先，但不是唯一来源；本地没有就主动联网查官方来源”长效治理规则。全面复查知识库全部 426 条 `proposed` 候选，不修改既有生命周期，不批量转正，不执行 merge。

## 一、核心统计口径与核验事实

- **复核候选总数**：**426** 条；
- **因旧规则“本地没有”被误判条数**：**275** 条（占全库 proposed 的 64.6%）；
- **现已从官方网络找到可靠来源条数**：**412** 条（覆盖率 96.7%）；
- **有条件在下一批转正条数（分类 1）**：**293** 条；
- **仍确实存在实质证据/适用性/版本门禁问题条数**：**133** 条。
