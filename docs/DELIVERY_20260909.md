## 已实现的结构

原件按 SHA 归档；检查记录和法规台账分别暂存；SQLite 是唯一母库，多 Sheet Excel 是受控查看/编辑入口。母库区分隐患、法规身份、法规版本、条款、依据关联、来源、证据和核验记录。JSON、搜索索引、法规索引、全文分片和 manifest 都由构建工具生成。

Excel 分开维护隐患库、法规库、法规版本、条款库、依据关联，另有标签、别名、替代关系、原始来源、核验记录、来源关联和来源定位等只读页。新增条目通过入库或目录提案完成；编辑已有内容会使相关核验失效，不能把状态单元格改成“已核验”来放行。

## 以后新增数据

1. 把 Excel/CSV/旧 JSON 放进 `source/imports/`，执行 `python tools/pipeline/imports.py source/imports`。已登记布局自动识别；新布局补字段映射。辅助页按表名和表头签名识别并记录跳过，未知业务页或歧义会明确拒绝。
2. AI 按法规版本整理和去重，复用一次取得的官方正文；审阅隐患、版本、条款和关联后，以提案更新母库。不确定项留在母库。
3. 执行 `python tools/pipeline/manage.py site --as-of YYYY-MM-DD --output NEW_SITE_DIR`，自动生成完整新网站包和私有增减报告。审阅发布差异后再处理正式部署。
