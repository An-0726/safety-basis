# 行车与自行车检索词义修正

## 问题与范围

用户搜索“行车”时，本站应按车间起重设备检索。原同义词组已有“起重机／行车／天车”，但所有变体均按任意子串匹配，因此“行车”会命中“自行车”，还会反向污染“天车”“起重机”的查询。原公开索引1764条中，这三个查询均返回40条，自行车条目排在“行车”结果前列。“自行车充电”还被切为“自＋行车＋充电”。

本次限定修正上述设备词义、相关组合问法及浏览器缓存更新。原定十步计划与PR131均已验收完成，本修正是用户新提出的独立问题，不恢复其他候选补录或全库审查。

## 修改后的行为

- “行车／天车／起重机”检索明确涉及起重设备的条目，不因“自行车”、道路车辆的“行车制动”或其他条款排除范围提及起重机械而命中。
- 设备对象以标题、既有别名或关键词核对；正文顺带提及不能替代对象。完整现有标题仍可精确定位，不因上述通用查询规则而失效。
- “起重机械／起重设备”作为设备总类相关检索，不将所有设备类型认作同一种起重机。
- “自行车”保留完整词；“自行车充电”“电动自行车飞线充电”仍按原对象检索。“行车吊钩”“行车限位”等问法须同时符合对象和缺陷。
- 类别筛选、原始输入、分享刷新、历史导航及手机布局保持可用。缓存命名空间由v14升级为v15，沿用既有升级协调机制。

## 验证与数量

在当前1764条公开索引中，“行车／天车／起重机”各返回23条，结果无自行车；“行车吊钩”3条、“行车限位”1条。“自行车充电”仍为8条，完整标题“电动自行车飞线充电”仍唯一命中原条目。法规搜索也不再将自行车管理办法作为起重规程结果。

新增11项针对设备词义、反例、复合问法、口语解释、对象字段、筛选及法规检索的回归测试；明确搜索“行车制动”“行车道”时仍保留完整词，不展开为起重设备。全部849项前端测试通过。知识库、条款、依据关联、审核记录及公开快照不变，公开数量仍为1764条。
