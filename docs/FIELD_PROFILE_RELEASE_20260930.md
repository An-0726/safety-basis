This change adds the governed reusable field-profile backend and its formal release validation. It does not complete the whole library's field classification, migrate the private pilot wholesale, or redesign the frontend.

## Included

- A separate versioned profile namespace with exact legal-link selection and independent semantic-review bindings
- Date-aware publication checks, mandatory explicit build date, and stable knowledge snapshots
- A public profile payload with exact bundle validation and private inventory exclusion
- Three reviewed conditional templates, reusing existing hazard identities: safety gas-alarm function failure, extinguisher bracket obstruction, and stored objects obstructing extinguisher access
- Corrected H003's mandatory location-sign wording and construction-project scope; retained two direct technical links and two scoped statutory supporting links
- Withdrew one unsupported statutory supporting association while preserving its identity and rejected history

Template approval never establishes facts about a particular enterprise. Each use still requires the stated applicability and observed evidence. The default website interface is unchanged; the governed profile payload is available for subsequent UI integration.

## Current reviewed projection

- 1,663 hazards
- 67 referenced law versions
- 1,341 clauses
- 1,797 links
- 3 governed field profiles

These are publication counts, not a claim that all source material or all requested work is complete. Unreviewed profiles and private authoring inventory are excluded. Existing pilot artifacts retain their original pinned baselines; changes to upstream knowledge intentionally invalidate any old dependency-bound reviews when reused against a different baseline.

## Remaining scope

Whole-library field routing and semantic review, unresolved specialist source requirements, frontend search/classification integration, and final end-to-end project acceptance remain separate work. No source PDFs, enterprise records, private inventories, or machine-local files are included in this change.
