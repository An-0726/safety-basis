# 常用模糊叫法与歧义检索集中修正

## 本轮边界与终点

用户要求进一步完善模糊词。本轮固定120条自拟问法，覆盖电气、机械、消防、化学品、个体防护和管理6组；不是实际用户搜索日志。不新增法规、隐患、条款或专业审核，不为填补零结果扩张适用范围。

按“整理问题清单→修正→验证→发布验收”4步执行。当前清单与修正完成，860项前端测试、知识库、严格发布审计及来源完整性通过；最终包浏览器及远端检查在合并前核准，发布后取得线上验收结果即结束，不自动追加候选批次。

## 修改后的行为

- 补充排插、空开、RCD、龙门吊、电葫芦、空压机、护目眼镜、冲眼器、抽风柜等别称，区分同义词与设备总类的相关检索。未将电动葫芦一律认作某种桥式、门式起重机。
- PPE、RCD、SDS、LEL等英文词按完整词匹配并按同一边界排序，不在`copper`、`parallel`或无关编号内部凑命中。“天车”不因“露天车间”或“每天车辆”字片而命中。
- 增加53组明确的歧义或口语处置。消防门先区分防火门与疏散出口；气罐先核设备身份；报警器先核检测对象；操作证先核岗位与资格类型；年检、检定、校验按对象区分。输入保留原话，点击建议后才切换检索。
- 进一步查询的对象须出现在标题、既有别名、关键词或已通过内容指纹和精确依据关联校验的现场场景标题中；背景正文或排除范围顺带提及另一设备，不代替对象身份。验收使用与页面相同的已校验DataStore索引，包含15条场景记录。作业票按实际作业类别提供有条件入口，不靠整章动火背景提及凑结果。
- 区分缺失与损坏、未来到期与已超期、用品使用与单位配备、培训记录与设备维护记录。明确否定缺陷、未查明或已完成的表述，不删掉状态词后改判为缺陷；“没有断路器”仍保留其原缺失含义。
- 原有“没戴耳塞／口罩”从直接泛化改为有条件建议，避免混入安全帽等条目。相应两例迁入新测试，新增安全帽、采购责任及岗位需求反例，不以删除旧断言代替验证。
- 已有分类、筛选、分享和标题定位保持；缓存v15升v16，沿用现有更新协调机制。

## 逐项处置与数量

120条中37条直接检索，77条提供有条件建议，5条明确缺证或缺陷不匹配，1条保留无结果。“露天车间”没有描述具体缺陷，保留无结果而不误变为天车。“非零”不作为专业准确性指标。
