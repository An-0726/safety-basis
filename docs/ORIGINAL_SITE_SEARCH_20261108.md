# 原网站搜索、知识重构与加载改造

本批次针对 [原网站](https://an-0726.github.io/safety-basis/)，将用户追加的八项查询体验要求与知识扩充、旧条目重构一并实施。源码基线为 `595e30e6b3b2774334f21db1ba8a286ddf58f24e`，已实际读取的原包版本为 `2026.11.08.595e30e6b3b2`。主站、私有检查工作台分别核对各自发布版本；本记录不将工作台上线当作主站已更新。

## 1. 八项要求如何落地

|任务范围|实现与可观察结果|
|---|---|
|现场口语、简称、别名、常见错字、长句和词序|保留原话，受控整理已识别的对象和状态；显示解释或纠错。否定、已完成、是否、疑似等不会被作为噪声删除；未知长句可以保守零结果。|
|设备与问题准确区分|行车与自行车按完整对象识别；未设置、已安装后故障、检定超期、资料缺失分别处理。含糊通道、报警器和起重机故障给出用途或部件选择；电箱接地候选提示箱体、导体、箱门及施工条件。|
|一句话多个问题|各问题独立检索、分别计数和展示，可只看一组再返回全部。总数按稳定ID去重；某组筛选后为空不会掩盖另一组。|
|排序及结果展示|对象和缺陷优先在标题、可靠别名与受治理场景中相符，适用场景参与排序。卡片展示表现、依据摘要、条件及匹配高亮；正文偶然提词不能代替对题对象。|
|零结果和条件不足|区别事实未确认、需明确含义或条件、已知库内依据缺口、筛选排除、一般未匹配。筛选排除提供“清除筛选，保留问法”；检索候选与企业现场确认在页面和复制内容中明确区分。|
|分类与筛选|保留原六类入口与专业分类、地域、核查用途，补充行业或场所、设备和问题类型。来源仅用发布条目的标题、别名和场所；未能归类明确保留默认集合，不猜测法定行业身份。组合按交集执行、可分享恢复，手机用折叠筛选和可移除条件。|
|加载、缓存和版本|请求及响应体都有时限，有限重试；核心索引先可用，核查场景独立加载与重试。页面、全部模块引用和数据绑定同一发布版本，跨版或哈希不符显示原因与恢复入口；脚本启动失败也不再只停留在初始化字样。|
|改前改后实际查询验收|同一批原话对旧引擎/旧发布包与新引擎/新发布包实际运行，保留逐例Top3、解释、建议和指标。调试样例、首次留出、披露后回归、另取二次留出分别记录，所有样本标注合成来源。|

上述导航与检索解释均不构成现场隐患确认。选择建议不自动补齐场所、责任主体、设备用途和实测事实。正式完整标题仍作为条目查阅入口，保留同名稳定ID及原有法规库、详情、分享、历史、分页能力。

## 2. 知识库和旧条目一起重构

实际读取市场监管总局公布的 [《中华人民共和国危险化学品安全法》官方全文](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2026/art_4e160e51cc134696a183a5f531f097e5.html)，核对第三十八条完整两款、责任主体及第五十二条范围边界和第一百二十七条施行日期。按第三十八条第一款，将复合状态拆成三个可区分条目：

|稳定ID|本次内容|边界|
|---|---|---|
|`H_2456A494C71E6807975B908C_1`|保留原ID，收窄为未设置通信装置或报警装置|分别记录实际缺失的装置，不要求两者同时缺失；已经设置后失效另查对应状态。|
|`H_0A53849CB39848628056FDADEB`|实质重构原候选，已设置的报警装置未保持适用状态|限危险化学品生产、储存单位作业场所，必须核实实际功能异常，不由缺报告、检定超期或“报警器”字样推定。|
|`H_HAZCHEM_COMMUNICATION_DEVICE_INOPERABLE`|新建独立通信装置失效分支|完整承接原复合条目已包含的通信适用状态义务，避免拆分报警条目时遗漏；设备与报警装置分别检索。|

危化装置拆分新建2个直接关联、1个官方证据。旧GB50058错配关联继续为rejected；完整原定义、旧审核和拒绝链留在previousEntity/previousReview。当前公开补充说明不再混入无标识的历史误引。核验明确为作者法源与范围复核，企业事实与独立人工专业签审均为false。技术选型、气体种类、阈值、探头位置、检测周期和重大事故隐患属性不得由该通用义务推导。

分类复核另发现南京地方条目被投影成全国的实际错误。已实读 [南京市人大常委会公告第27号](https://rd.nanjing.gov.cn/xxfb/cwhgg/202505/t20250506_5140604.html)：第二条限定本市行政区域，第四十七条规定消火栓与疏散/消防通道等义务。将该条款及三个直接关联的错误CN地域码收窄为CN-3201，逐个保留原记录与审核，新增完整第二条、第四十七条证据。关联的三项原H条件本来就明确南京，本次未扩大义务和地域。

发布投影按已审的规范化地域码求K、C、法规版本和法规身份的最窄兼容范围，忽略自然语言scope，遇不兼容地方代码不猜全国。检索地区只由直接或备选依据决定，全国辅助依据不能扩大地方条目的可用范围。详情、条款、核查场景与索引使用相同地域规则；这些是导航与投影更正，不宣称对每个既有条目的全部法律内容重新专业签审。

## 3. “数据库正在初始化”的实际排查

原站在本次云浏览器中最终可以完成加载，因此没有将某位用户的永久卡住冒称为已逐网复现。源码和故障注入确认了能导致同一表象的路径：原请求缺少时限；初始化要等待15个场景的逐项详情/条款校验；任一请求或响应体挂起会阻塞搜索入口；跨次部署的旧壳、脚本和数据也缺少完整模块图的同版绑定。

本轮核心数据先校验后开放搜索，场景资料并发核验、完整通过才接入；场景失败时保留核心搜索并显示独立重试。单次数据请求默认12秒、最多自动重试1次，仅重试适用的网络/服务器故障；格式、完整性和版本错误不靠无限重试掩盖。模块启动看护在20秒仍未启动时提供恢复入口。旧请求取消后不能覆盖新一轮结果。

发布构建在页面meta、客户端版本和静态模块依赖中注入同一dataVersion；三种页面与全部模块引用进行构建核验，数据继续按清单和SHA256校验。Service Worker只按完整版本URL取对应壳资源，不把旧数据当新数据回退。恢复操作只清理本站命名空间的缓存和本站scope注册，不清除其他网站数据。

加载、响应体中断、失败后重试、跨版本、场景延迟、并发分片共享和旧请求回写均有定向回归；真实Chromium故障注入随现有发布工作流运行，产物保留在`browser-check/search-ux`。

首次运行发现“拉线充电”的召回遗漏、检定证书未出示的资料提示遗漏、普通工业车间油污的已知依据缺口未识别、配电箱尚未安装的条件提示遗漏。修复后全部进入回归，第三列不再称为独立留出。未为提高命中删除否定样本，也未把条件建议跳转后命中算作原句直接命中。

定向误匹配只统计已列明禁止H，或明确应不产生直接候选的样本出现结果；不是对所有候选逐条专业评审得到的误报率。零结果包括应当保守不返回条目的情形，应与“应有内容却零结果”分开看。

第二组由未参与搜索实现的审查者只依用户范围和公开条目盲编，期望ID限制在旧公开1764条与当前包的交集中。SHA256为`6cfd379b4c97bfc62a234b8d982c20c5a5d24ac7ab08d6972c1adf7de9ecee3e`。它包含更复杂的长句、母设备与附件、共享对象的后续描述、明确缺陷与另一否定事实并存。

第二组首次实际结果为：原版阳性Top3 **0/10**、新引擎 **1/10**；新引擎定向误匹配1例、原始零结果16例、阳性零结果8例，全部契约通过9/20。该失败阻止了发布。由此进行通用对象和状态作用域修复：不能把“固定式压力容器”的“固定”当作一个缺陷切分；背景部位不能与真正故障设备变成必须同时满足的对象；“检定超期但没有损坏”应保留超期事实，同时排除损坏；“没有被杂物堵住”必须保留否定。第二组披露后改为回归，首次失败不覆盖。

其中H2_01原标签只接受概括的“灭火器失压”，新引擎实际返回更具体的压力指示针未在绿色范围条目；该结果具有合理性，但原始严格标签和首次分数没有事后改写。最终报告可据逐例记录区分标签局限与解析缺陷，不能把这类事后判断充作独立评分。

最后另取第三组20条：10阳性、10边界，2条多问题，7条至少50字长句；SHA256为`0e6d8366da7bfa4db6a5be8e45381dac929e755464c8adb8fc68a05abeea80c5`。编制者仍未读取引擎、测试和评分，只据公开条目核对可接受的具体项与概括项；冻结后才运行。最终成绩见同目录，不因失败继续无限换题或改变标注。

## 6. 重放、发布与实际限制

重放当前版本：

```sh
node tools/checks/search_ux_eval.mjs --bundle source/releases/current \
  --cases docs/search-acceptance-20261108/dataset-v1.json --out tmp/search-v1.json
node tools/checks/search_ux_eval.mjs --bundle source/releases/current \
  --cases docs/search-acceptance-20261108/dataset-v2.json --out tmp/search-v2.json
python tools/browser/audit_search_ux.py --bundle source/releases/current --out tmp/browser-search
```

旧版重放使用基线提交的独立checkout、对应已构建发布包，传入`--source-root`；不能拿新引擎运行的结果标成改前结果。样本和报告保留数据版本、发布hash、实现指纹、逐问题Top3及全部标注；源库日期回放不等于实际历史发布记录。

既有Node、Python管线、知识绑定、严格发布、来源完整性、公开快照和私有工作台兼容检查继续执行，没有降低既有门槛。当前执行环境不能启动本地Chromium，因此本地DOM/单测与GitHub真实浏览器验收分别记录；现有Actions增加23项原站交互、窄屏与恢复检查，最终生产提交由对应PR、Pages部署和线上manifest一起确认。

规则式解析仍有词表和场景覆盖边界，尤其是未识别设备、复杂省略、跨句指代、精确数值和未提供的法定条件；保守零结果或核实提示不代表义务不存在。知识库保留265条待补证候选和11条active排除；本批次完成的是有证据支撑的扩充与旧条目重构，不将缺证条目批量转正。
