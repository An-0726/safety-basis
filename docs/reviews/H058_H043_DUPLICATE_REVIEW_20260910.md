# H058 / H043 重复判定

日期：2026-09-10
状态：建议合并，尚未执行数据合并

## 判定

H058《仓储场所在岗人员消防安全教育频次不足》与 H043《仓储场所未按要求开展消防安全教育培训》属于同一规范义务的重复表达。

H043 已完整覆盖两类义务：
- 员工上岗、转岗前消防安全培训；
- 在岗人员至少每半年一次消防安全教育。

H058 的 description、conditions、places 和 measures 均落在 H043 的覆盖范围内，没有形成独立检查对象或独立义务边界。因此建议保留 H043 作为主 hazard，H058 保留 Stable ID 并合并至 H043，而不是删除历史实体。

## 合并前检查

正式合并前应先核对 H058 当前 links / review binding，确认没有 H043 尚未承接的唯一有效依据；如存在，应先判断是否应迁移到 H043。随后按现有 merged hazard 处理方式更新 H058 lifecycle、mergedInto、关联状态及审核内容哈希。

## 风险控制

不得只改 hazard lifecycle 而遗留仍被视为可发布的 active link；也不得为完成合并而删除 Stable ID 或历史审核记录。
