# H049 专业终审记录（2026-09-10）

## 结论

H049 `生产安全事故发生后主要负责人未及时组织抢救并如实报告` 的现行精确直接依据保留为《中华人民共和国安全生产法》（2021年修正）第八十三条。

本轮复核确认：库内已经完成该条款、H049 → 第八十三条直接关联及其适用性审核；无需重复创建法规、条款、关联或 Stable ID。

终审结果：**PASS**。

## 隐患与条款对应关系

H049 当前核心事实为：

- 生产经营单位发生生产安全事故；
- 单位负责人已经接到事故报告；
- 未迅速采取有效措施组织抢救；和/或
- 未按照国家有关规定立即、如实向当地负有安全生产监督管理职责的部门报告。

《中华人民共和国安全生产法》（2021年修正）第八十三条明确规定，生产经营单位发生生产安全事故后，事故现场有关人员应当立即报告本单位负责人；单位负责人接报后应迅速采取有效措施、组织抢救，并按照国家有关规定立即如实报告，不得隐瞒不报、谎报或者迟报，也不得故意破坏事故现场、毁灭有关证据。

因此，第八十三条与 H049 的监管对象、事故阶段、义务主体、组织抢救义务和事故报告义务均直接一致，属于精确直接依据。

## 对历史第八十一条关联的判断

2021年修正后的《安全生产法》第八十一条规定的是生产经营单位制定生产安全事故应急救援预案并与地方预案衔接、定期组织演练的义务。

该条并不直接规定“事故已经发生且单位负责人接报后组织抢救、立即如实报告”的义务，因此不能作为 H049 的直接依据。库内既有对该误配关联的 rejected 处理应继续保留，不恢复为有效依据。

## 国务院第493号令的补充核对

同时复核《生产安全事故报告和调查处理条例》（国务院令第493号）：

- 第九条对事故发生单位负责人报告事故的时限作了更具体规定；
- 第十四条要求事故发生单位负责人接报后立即启动相应应急预案或者采取有效措施，组织抢救，防止事故扩大，减少人员伤亡和财产损失。

这两条与 H049 有专业相关性，但当前 H049 的文字仅要求“按规定及时、如实报告”和组织抢救，没有写入“1小时内报告”等更细化事实。现有《安全生产法》第八十三条已经完整、直接覆盖 H049 当前事实和整改要求。

按照 V4 “直接适用、避免无意义堆砌”的原则，本轮**不为了增加依据数量而新增国务院第493号令关联**。以后若形成“事故发生单位负责人未在法定时限内上报事故”这一更具体隐患，可单独评估第九条作为更精确依据。
