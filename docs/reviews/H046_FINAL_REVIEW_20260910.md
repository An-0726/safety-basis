# H046 专业终审记录（2026-09-10）

## 结论

H046 `江苏生产经营单位主要负责人未按要求组织季度安全生产全面检查` 的现行精确直接依据确认为《江苏省安全生产条例》（2023年修订）第十五条第一项。

该条直接规定生产经营单位主要负责人应当每季度至少组织并参与一次安全生产全面检查，并研究分析、解决安全生产存在问题，与 H046 的地域、主体、频次、行为和履职内容一致。

终审结果：**PASS**。

## 隐患与条款对应关系

H046 当前核心事实为：

- 场所主体为江苏省行政区域内的生产经营单位；
- 义务主体为生产经营单位主要负责人；
- 未做到每季度至少一次；
- 未按要求组织并参与安全生产全面检查；
- 检查目的包括研究分析和解决安全生产存在问题。

《江苏省安全生产条例》第十五条第一项对上述主体、频次和行为均作出直接规定，因此属于地方专项直接依据，不应使用仅规定一般性主要负责人职责的全国法律条款替代这一具体季度频次要求。

## 现行版本与适用范围

江苏省人大常委会于2023年3月30日修订《江苏省安全生产条例》，江苏人大网于2023年4月10日公开现行正文；条例自2023年7月1日起施行。

条例第二条规定，在江苏省行政区域内从事生产经营活动的单位的安全生产及其相关监督管理适用本条例。H046 已明确限定江苏生产经营单位，因此地域适用边界清晰。
