# H048 专业终审记录（2026-09-10）

## 结论

H048 `江苏生产经营单位主要负责人未按要求组织年度全面安全风险辨识` 的现行精确直接依据确认为《江苏省安全生产条例》（2023年修订）第十五条第三项。

该条直接规定生产经营单位主要负责人每年至少组织一次全面的安全风险辨识，并制定完善管控措施，与 H048 的地域、主体、年度频次、全面风险辨识和管控措施要求一致。

终审结果：**PASS**。

## 隐患与条款对应关系

H048 当前核心事实为：

- 场所主体为江苏省行政区域内的生产经营单位；
- 义务主体为生产经营单位主要负责人；
- 未做到每年至少组织一次；
- 未组织全面的安全风险辨识；和/或
- 未制定完善相应管控措施。

《江苏省安全生产条例》第十五条第三项对上述主体、频次、行为和结果要求均作出直接规定，因此属于地方专项直接依据。全国法关于主要负责人组织建立并落实安全风险分级管控和隐患排查治理机制的一般职责，可以说明上位义务，但不能替代江苏条例明确的“每年至少一次”地方频次要求。

## 现行版本与适用范围

江苏省人大常委会于2023年3月30日修订《江苏省安全生产条例》，江苏人大网于2023年4月10日公开现行正文；条例自2023年7月1日起施行。

条例第二条规定，在江苏省行政区域内从事生产经营活动的单位的安全生产及其相关监督管理适用本条例。H048 已明确限定江苏生产经营单位，因此地域适用边界清晰。
