1 范围


  本文件规定了低压铸造机及其他金属型铸造设备的安全要求和/或风险减小措施及使用信息,描述
了相应的验证方法。
  本文件列出了当低压铸造机及其他金属型铸造设备按规定用途使用以及在制造商可合理预见的误
用条件下使用时,与该类设备有关的重大危险、危险状态或危险事件示例(见附录 A)。
  本文件适用于低压铸造机及其他金属型铸造设备的设计、制造和验收。
  注:低压铸造机及其他金属型铸造设备包括低压铸造机、差压铸造机、金属型重 力 铸 造 机、离 心 铸 造 机、金 属 型 铸 造
    自动化生产单元及生产线。
  本文件不适用于压铸机和压铸单元、挤压铸造机、旋压设备、连续或半连续铸造机。

4 安全要求和/或风险减小措施

4.
 1 通则

4.1 低压铸造机及其他金属型铸造设备(以下简称“机器”)的安全要求应符合 GB20905 和本文件的
 1.
规定。
4.2 对于本文件未涉及的相关非重大危险,机器应按照 GB/T15706—2012 规定的原则进行设计。
 1.
 1.
4.3 机器设计时应进行风险评估,并采取减小风险的措施。
   注:附录 A 列出了经风险评估识别为本类机器需要采取措 施 消 除 或 减 小 风 险 的 重 大 危 险,以 及 危 险 状 态 和 危 险 事
       件示例。
4.4 机器的风险评估及其实施过程中所采用的方法见 GB/T15706—2012 中第 5 章和 GB/T16856。
 1.
 1.
4.5 减小机器风险的首要措施,是进行本质安全设计,即通过适当选择机器的设计特性和/或暴露人
员与机器的交互作用,消除危险或减小相关风险。
 1.
4.6 通过设计不能避免的危险,应采取安全防护(使用防护装置和/或保护装置)及补充保护措施。
 1.
4.7 对于无 法 通 过 设 计 和 采 取 安 全 防 护 措 施 而 避 免 的 剩 余 风 险,应 采 用 使 用 信 息 通 知 或 警 告 操
作者。
 1.
4.8 对于本文件不同章条描述 的 机 器 和/或 机 器 功 能 的 组 合 如 果 位 于 同 一 危 险 区 域,需 同 时 考 虑 不
同机器的减小风险的措施。

4.
 2 一般要求

 2.
4.1 机器结构

 2.
4.1.
   1 机器及其零部件的强度和刚度应满足机器在按规定条件下的储运、安装和使用要求。

   2 机器易接触的外露部位不应有引起人体损伤的尖角、锐边,密封罩、检修门、盖板等薄板件的棱
边应倒钝、折边或修边,可能引起划伤的管端开口应包覆。
 2.
4.1.
   3 机器上的螺栓、螺钉、螺母等紧固件,应采取防松措施。
 2.
4.1.
   4 机器的结构和外形布局应确保其稳定性,在按规定条件储运、安装和使用时,不应因偏重、稳定
性差存在意外翻倒、掉落或自行移动的危险。
 2.
4.1.5 由于机器的形状特殊等原因不能确保其稳定性时,应采取措施实现其稳定性,包括但不限于:
   a) 地脚螺栓;
   b) 锁定装置;
   c) 运动限制器或机械式停机装置。
 2.
4. 6 机器配套的压力容器类零部件(例如,气力输送发送罐)的制造、检验和验收应符合 GB/T150.

的规定。
 2.
4.1.
   7 起吊装置的位置设计应正确,防止机器起吊时出现偏重而失去稳定性。
 2.
4.1.
   8 防止被加工材料或碎块(如砂芯、铸件及其余料)飞出,机器应设置相应的能承受可以预料的冲
击负荷的防护隔离。

4.2 运动部件

 2.
4.2.
   1 人员易触及并有可能造成伤害的运动部件,应设置防护装置。
 2.
4.2.
   2 对于因工艺需要不能设置防护装置的运动部 件,应 在 其 端 部 或 突 出 部 位 喷 涂 表 示 危 险 位 置 的
黄色和黑色相间条纹的安全标记,安全标记应符合 GB2894—2025 中 4.
                                      3 的规定。
 2.
4. 3 对于有可能造成缠绕、吸入或卷入等危险的运动部件,例如,传动装置(如丝杆、齿轮、滚筒等),
  2.
应封闭或设置其他防护装置,并在其邻近位置设置警告标志。
 2.
4.2.
   4 带有活动罩盖的运 动 部 件,应 设 置 开 盖 危 险 和/或 机 器 停 止 运 行 后 才 允 许 打 开 罩 盖 的 警 告 标
志,或设置罩盖与运动部件的联锁装置。
 2.
4. 2.
    5 运动部件与运动部件之间或运动部件与静止部件之间防止人体部位挤压的间距应符合
GB/T12265—2021 的规定,当无法满足要求时应采取防护措施。
 2.
4.2.
   6 运动部件停止前应采取减速措施,应使其停止时不会产生冲击、碰撞危险。运动部件行程两端
均应设置可靠的机械极限限位装置。
 2.
4.2.
   7 运动部件失能时应停止在原地,不应产生其他意外动作。
 2.
4.2.
   8 夹具在转运过程应确保物体不晃动、掉落,失能时应夹持有效;若在高空转运,其下方应有横向
固定式防护装置,强度应能承受物体掉落的冲击;转运路径下方的管线有防砸损防护。

4.4 电气设备

 2.
4. 1 电气设备应符合 GB/T5226.
  4.                 1—2019 的规定。
 2.
4. 2 电气柜的外壳防护等级不应低于 GB/T4208—2017 规定的IP54。
  4.
 2.
4.4.
   3 存在电击危险的电气设备应在其外壳或护罩上设置预防触电的警告标志。
 2.
4.4.
   4 往复运行的线路应采用软电缆。
 2.
4.4.
   5 因熔融金属飞溅、高温辐射等造成电绝缘失效的电气设备及线路应采取隔热、防烫防护措施。

 2.
4.5 控制系统

 2.
4.5.
   1 控制系统应能按规定动作顺序实现联锁。
 2.
4.5.
   2 电气联锁应具备防止因误动作引起的意外故障和/或危险事件发生的功能。
 2.
4.5.
   3 控制系统应具备必要的自动监控功能,在出现 某 一 故 障 时 触 发 报 警 器 和 在 故 障 排 除 前 不 可 能
启动一次新的工作循环。
 2.
4. 4 如果设备有不同的工作模式(如手动、半自动、自 动 等),则 应 对 不 同 的 工 作 模 式 分 别 采 用 带 有
  5.
钥匙锁定的选择开关或带有可卸手柄的转换开关。
 2.
4.5.
   5 控制系统中的暂停、停止装置复位后不应引发任何危险情况。
 2.
4.5.
   6 当动力 或 控 制 信 号 中 断 时,制 动、夹 紧、翻 转、提 升 或 下 降 等 动 作 应 能 立 即 停 止 并 保 持 当 前
状态。
 2.
4.5.
   7 应采取措施防止动力供应失效带来的危险,包括动力不稳定、动力供应中断之后或控制回路被
切断时的意外重启;防止机器意外启动的控制系统内置安全措施应符合 GB/T19670 的规定。
 2.
4. 8 控制系统有关安全防护方面的设计应符合 GB/T16855.
  5.                             1 的规定。

4.6 气动和液压系统

 2.
4. 1 气动系统的安全要求应符合 GB/T7932 的规定。
  6.
 2.
4. 2 液压系统的安全要求应符合 GB/T3766 的规定。
  6.
 2.
4.6.
   3 元器件、配件的选择应保证当系统投入预定的使用时能在额定极限内可靠运行。
 2.
4.6.
   4 高压气动系统、液压系统应安装有自动泄压装置。

  6.
该温度时应自动报警。
 2.
4.6.
   6 液压系统的蓄能器应有自动泄压装置。
 2.
4.6.
   7 因熔融金属飞溅、高温辐射等造成失效的液压和气动设备及管路应采取隔热、防烫防护措施。
